# בוט מלאי לאמזון הודו

כל בוקר (ברירת מחדל 6:30–9:30 שעון ישראל) הבוט בודק את כל דפי הגיפט קארד במקביל כל ~10 שניות,
ומחוץ לחלון הזה בדיקה אחת כל כמה דקות, כל עוד המחשב ער.
ברגע שכפתור הקנייה מופיע תקבל בטלגרם 🚨 עם קישור ישיר. אם דף שהיה "אזל" משתנה למשהו לא מוכר, תקבל קודם 👀 (התראה מוקדמת).
הוא יתריע שוב רק אם המוצר ייגמר ויחזור, ויודיע ❌ כשהוא נגמר.

## הקמה
1. **בוט טלגרם:** בטלגרם, פתח שיחה עם `@BotFather`, שלח `/newbot` ושמור את הטוקן.
   אחר כך שלח הודעה כלשהי לבוט החדש, ופתח בדפדפן
   `https://api.telegram.org/bot<הטוקן>/getUpdates` וחפש את `"chat":{"id": ...}`. זה ה-Chat ID.
2. שמור את שניהם כמשתני סביבה של המשתמש ב-Windows: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
3. הבוט רץ מ-Task Scheduler: `Amazon morning watch` (כל בוקר) ו-`Amazon all-day check` (כל כמה דקות).

## לוח בקרה
`dashboard.cmd` פותח את הלוח ב-`http://127.0.0.1:8765`. שם עורכים שעות, מרווח בין בדיקות, בדיקה לאורך היום וקישורי מוצרים,
ורואים התראות והיסטוריית בדיקות. **Test Telegram** בודק פעם אחת ושולח את מצב כל מוצר.

## טיפים
- בטלגרם: פתח את הבוט → שם הבוט → Notifications → צליל בולט, כדי שההתראה לא תתפספס.
- היה מחובר לאפליקציית אמזון עם אמצעי תשלום שמור, כך שמההתראה נשארות רק לחיצת Buy Now ואישור.
- אם מגיעות התראות ⚠️ על CAPTCHA, הגדל בלוח את הזמן בין בדיקות (למשל ל-15).
