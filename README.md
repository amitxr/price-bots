# בוט מחירים ל-Eneba (PSN India)

נכנס לדף כל 12 שעות, קורא את הכרטיס שמסומן **Best value**, מחשב כמה INR מקבלים לכל ₪1,
ושולח הודעת טלגרם אם השער הגיע לסף (ברירת מחדל: 24).

## הקמה (פעם אחת, בערך 10 דקות)

1. **בוט טלגרם:** בטלגרם, פתח שיחה עם `@BotFather`, שלח `/newbot` ושמור את הטוקן.
   אחר כך שלח הודעה כלשהי לבוט החדש, ופתח בדפדפן:
   `https://api.telegram.org/bot<הטוקן>/getUpdates` וחפש את `"chat":{"id": ...}`. זה ה-Chat ID.
2. **ריפו ב-GitHub:** צור ריפו חדש (אפשר פרטי) והעלה אליו את כל הקבצים מה-zip, כולל התיקייה `.github`.
3. **סודות:** בריפו, Settings → Secrets and variables → Actions:
   - בלשונית **Secrets**: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
   - בלשונית **Variables**: `THRESHOLD` = `24`
4. **בדיקה:** Actions → Eneba price check → Run workflow.
   בפעם הראשונה כדאי להוסיף Variable בשם `ALWAYS_NOTIFY` = `true` כדי לקבל הודעה גם מתחת לסף, ולמחוק אותו אחרי שרואים שזה עובד.

## שינוי הגדרות

| משתנה | מה הוא עושה |
|---|---|
| `THRESHOLD` | הסף ב-INR לכל ₪1. לשנות ל-25 למשל, בלי לגעת בקוד |
| `ALWAYS_NOTIFY` | `true` = הודעת סטטוס בכל ריצה |
| `PRODUCT_URL` | לעקוב אחרי דף אחר ב-Eneba |

השעות מוגדרות ב-`.github/workflows/eneba-check.yml` (שורת `cron`, בשעון UTC).

## הערות
- אם האתר חוסם או משנה עיצוב, תקבל הודעת ⚠️ במקום שקט.
- אם Eneba מציג מחירים בדולר/יורו לשרת של GitHub, הבוט ממיר לשקלים אוטומטית לפי שער יומי.
- GitHub משבית ריצות מתוזמנות בריפו שלא היה בו שינוי 60 יום; יגיע מייל, ולוחצים "Enable" מחדש.

# בוט מלאי לאמזון הודו (בוקר)

כל בוקר, מ-6:30 בערך ועד 9:15 שעון ישראל, הבוט בודק את דף הגיפט קארד כל ~25 שניות.
ברגע שכפתור הקנייה מופיע תקבל בטלגרם 🚨 עם קישור ישיר. הוא יתריע שוב רק אם המוצר ייגמר ויחזור.

## הקמה
משתמש באותו ריפו ובאותו בוט טלגרם. אין צורך בסודות חדשים.

⚠️ **הריפו חייב להיות ציבורי (Public).** ריצה של כ-2.5 שעות ביום צורכת יותר מ-2,000 הדקות
החינמיות שיש לריפו פרטי בחודש. בריפו ציבורי הדקות חינמיות ללא הגבלה, והסודות (טוקן טלגרם) נשארים מוסתרים.

**בדיקה:** Actions → Amazon morning watch → Run workflow (עם "Test mode" מסומן).
הבוט יבדוק פעם אחת וישלח לך את שם המוצר ואת המצב שלו. כך תדע שהוא מזהה נכון את הדף.

## הגדרות (Variables)
| משתנה | ברירת מחדל | מה הוא עושה |
|---|---|---|
| `AMAZON_URLS` | שני הקישורים ששלחת | כמה קישורים מופרדים בפסיקים, למשל כמה סכומים |
| `END_TIME` | `09:15` | מתי להפסיק, שעון ישראל |
| `INTERVAL` | `25` | שניות בין בדיקות. נמוך מדי = יותר סיכוי ל-CAPTCHA |

## טיפים
- בטלגרם: פתח את הבוט → שם הבוט → Notifications → צליל בולט, כדי שההתראה לא תתפספס.
- היה מחובר לאפליקציית אמזון עם אמצעי תשלום שמור, כך שמההתראה נשארות רק לחיצת Buy Now ואישור.
- אם תקבל ⚠️ על CAPTCHA, אמזון חוסמת את השרתים של GitHub. במקרה כזה אפשר להריץ את `amazon_bot.py` מהמחשב בבית.
